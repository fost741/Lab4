# Практична робота №4: Статичні поля, властивості, методи

## Предметна область
Програма моделює предметну область **«Музичні інструменти»** (`Instruments`).

### Кожен об'єкт класифікується за:
* **назвою** (`name`) та **брендом** (`brand`): *Yamaha, Gibson, Pearl, Roland*.
* **сімейством** (`family`): *Strings, Woodwinds, Brass, Percussion, Keyboard*.
* **типом живлення**: акустичний або електронний (`isElectric`).
* **кількісними параметрами**: кількість струн (`stringCount`) та клавіш (`keyCount`).
* **поточним станом**: підключення до мережі (`isConnected`), налаштованість (`isTuned`) та рівень гучності (`currentVolume`).

## **Мета роботи**
- Навчитися створювати та застосовувати статичні поля класу (`static private fields`);
- Ознайомитися з реалізацією статичних властивостей (`static public properties`);
- Набути навичок створення та використання статичних методів, засобів парсингу рядків (`Parse`, `TryParse`) та перевизначення методу `ToString()`.

---

## 1. **Статичні поля та властивості класу `Instruments`:**
   * **`validCount` / `ValidCount`:** статичне лічильник-поле та public-властивість тільки для читання, що зберігає кількість коректно створених об'єктів предметної області.
   * **`totalCount`:** статичний лічильник для формування унікального реєстраційного коду інструмента (`REG-01`, `REG-02` тощо).
   * **`maxAllowedVol` / `MaxAllowedVolume`:** статична властивість для загального обмеження допустимого рівня гучності (0–100%) для всіх інструментів у системі з перевіркою діапазону.

## 2. **Статичні методи класу:**
   * **`Instruments.Parse(string input)`:** метод перетворення рядка формату (`Name, Family, Brand, IsElectric, KeyCount, StringCount`) на об'єкт класу `Instruments`. Містить повну валідацію типів даних та генерує відповідні винятки (`FormatException`, `ArgumentException`).
   * **`Instruments.TryParse(string input, out Instruments instrument)`:** безпечний метод створення об'єкта з рядка, який викликає `Parse` та повертає `bool`-результат без вивалювання програми.
   * **`Instruments.CalcRecommendVolume(double roomArea)`:** прикладний статичний метод для розрахунку рекомендованого рівня гучності на основі площі приміщення (m**2).

## 3. **Перевизначення методу `ToString()`:**
   * Метод `public override string ToString()` перетворює об'єкт розробленого класу на рядок уніфікованого формату (`name, family, brand, isElectric, keyCount, stringCount`), який повністю підтримується статичними методами `Parse` та `TryParse`.

## 4. **Оновлене меню:**
   * `1 – Add new` `3. Add in one string format`: створення об'єкта через парсинг рядка з використанням `Instruments.Parse()`.
   * `2 – Show all objects`: відображення таблиці інструментів з додатковим виведенням значення статичного лічильника `Current valid instruments count`.
   * `3 – Search for object`: пошук об'єктів за критеріями.
   * `4 – Show behaviour`: демонстрація методів екземпляра.
   * `5 – Delete object`: видалення об'єкта за номером.
   * `6 – Show static methods`: демонстрація роботи статичних методів:
     * Зміна загального обмеження максимальної гучності `MaxAllowedVolume`.
     * Розрахунок рекомендованої гучності `CalcRecommendVolume` за площею приміщення.
   * `0 – Exit`: завершення роботи програми.
